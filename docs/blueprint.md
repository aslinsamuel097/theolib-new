# **App Name**: Theos Lib

## Core Features:

- User Authentication: Secure login and registration for students.
- Book Browsing: Browse the theological library catalog.
- Book Search: Advanced search functionality to quickly locate books by title, author, or topic.
- Book Preview: Enable users to preview books (table of contents, first chapter) via online reader before borrowing.
- Borrowing System: Allow students to virtually 'borrow' books for a 5-day period.
- Borrowing Expiration Tool: AI tool for automatically restricting access to borrowed books at the end of the 5-day loan.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke a sense of trust and knowledge.
- Background color: Light gray (#F5F5F5) for a clean and readable layout.
- Accent color: Gold (#FFC107) to highlight important elements and calls to action.
- Body font: 'Literata', a serif font, to ensure readability for long texts.
- Headline font: 'Alegreya', a serif font, for titles and headers to create a classical, trustworthy style.
- Use simple, professional icons to represent library functions. Consider icons from the Material Design set.
- Implement a clean, intuitive layout. Utilize whitespace effectively to reduce clutter.
- Use subtle animations for transitions to enhance user experience without distracting from the content.
